# Contributing to FlockSense

Thank you for your interest in contributing to FlockSense!

## Development Workflow

1. **Fork or Clone the Repository**:
   ```bash
   git clone https://github.com/Muthudeenathayalan/FlocksensePrediction.git
   ```

2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/amazing-feature
   ```

3. **Commit Your Changes**:
   Follow semantic commit message conventions:
   - `feat:` for new features
   - `fix:` for bug fixes
   - `docs:` for documentation updates
   - `refactor:` for code cleanups

4. **Run Code Analysis & Tests**:
   ```bash
   flutter analyze
   flutter test
   ```

5. **Open a Pull Request**:
   Submit your pull request describing the rationale and changes introduced.
