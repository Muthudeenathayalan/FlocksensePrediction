# Veterinary Protocols & Health Triage Matrix

This protocol manual guides field veterinarians responding to automated alerts generated by FlockSense.

---

## 1. Automated Triage Workflow

```
[ Anomaly Alert Triggered ]
          │
          ▼
   [ Severity Assessment ]
   ├── High Mortality (> 1%) ──► Urgent Site Visit + Autopsy Sampling
   ├── Respiratory Symptoms ──► Tracheal Swab PCR for NDV/IBV
   └── Enteric Symptoms     ──► Intestinal Scraping & Fecal Oocyst Count
          │
          ▼
[ Digital Prescription in App ]
          │
          ▼
[ Farmer Medication Schedule & Withdrawal Period Timer ]
```

---

## 2. Mandatory Withdrawal Period Guidelines

When prescribing antibiotics or coccidiostats, veterinarians must specify the withdrawal duration in FlockSense:
- **Enrofloxacin**: 7-day withdrawal prior to slaughter.
- **Tylosin**: 3-day withdrawal.
- **Amoxicillin**: 1-day withdrawal.

The app automatically locks bird sales dispatch if a batch is within an active medication withdrawal window.
